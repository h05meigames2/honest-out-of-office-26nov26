One brutally honest but still polite out-of-office auto-reply for the
[make.fun bounty](https://make.fun/bounty/u-po-pu-the-painfully-honest-out-of-office-63e7ca0b).

## The reply

> I'm away until Monday. Your email will be read, sighed at, and answered in the order I feel brave enough to face it — thank you for your patience.

## How it works

`main.py` writes that single line to `/output/entry.txt` (146 characters,
inside the 1–200 character gate, valid UTF-8, not only white space).

```sh
python3 main.py
cat /output/entry.txt
```

## Why this line

It admits something a real employee would only say privately — that the
inbox is triaged by courage, not by arrival order — while keeping a warm,
professional tone a manager would not object to.
